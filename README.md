# 🤖 Jarvis – Retrieval-Augmented AI Knowledge Assistant

An AI-powered knowledge assistant that allows users to upload documents and ask questions using Retrieval-Augmented Generation (RAG). It uses embeddings, vector search (ChromaDB), and a local LLM (Ollama) to generate accurate, context-aware answers with optional voice input and audio output.

---

## 📦 Installation & Setup

```bash
git clone https://github.com/Laxmikanta7260/jarvis-ai.git
cd jarvis-ai
pip install -r requirements.txt
ollama run llama3
uvicorn main:app --reload
```

Open: http://127.0.0.1:8000

---

## 🧪 Usage

1. Open the app in your browser  
2. Upload a file  
3. Ask questions  
4. See answers
